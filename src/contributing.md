# Contributing

Every page is a Markdown file in the `src/` folder of this book's GitHub
repository.

- **Fix a page:** click the pencil icon at the top right of the page.
- **Add a page:** copy `src/TEMPLATE.md`, then list it in `src/SUMMARY.md`.
- **Preview locally:** run `mdbook serve` and open `http://localhost:3000`.

The repository's README has the details.
